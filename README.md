# Лендинг курса для будущих родителей

Новая версия n-e-n.ru/school/kurs1 («Беременность, роды и первая неделя с новорожденным») в оформлении страницы Школы НЭН и лендинга «Первый год с малышом». Один файл `index.html` без сборки, стили и скрипт внутри. Разметка и стили — те же, что у `firstyear/`.

Структура: первый экран (кнопки «Купить за 4 500 ₽» и «Подарить курс», бонус Балансити) → фактоиды → «Что становится проще» → темы курса → «Не курс красивой беременности. Курс подготовки к ребенку» → отзывы → стоимость → «А если…» → подвал. Плашка с покупкой появляется, когда кнопка первого экрана ушла вверх, и прячется на блоке стоимости. Цена стоит только в кнопках.

## Как посмотреть

```bash
python3 -m http.server 8768
```

Затем открыть http://localhost:8768.

## Выкладка на n-e-n.ru/school/kurs1

- `index.html` заменяет старую страницу. Картинки лежат в `images/`; на сайте страница живет по адресу `/school/kurs1`, поэтому относительный путь `images/…` указывает в `/school/images/`. Имена новых файлов (`hero-pregnancy.svg`, `tired-pregnant.png`) там не заняты, а `logo-school.svg` нужно положить туда же или заменить путь.
- Ссылки абсолютные: оплата `/course/school/enroll`, подарок `/course/school/gift`, кабинет, оферта, другие курсы.
- Метрика: те же счетчики (41151484 и 110396040) и цели, что на старой странице: `buy_click`, `gift_click`, `hub_course_click`. Включается только на домене n-e-n.ru.
- og:image оставлен старый: `/school/images/tild3162-…facebook_post_-_scho.jpg`.

## Что сверить перед выкладкой

Тексты — со старой страницы, отредактированы голосом НЭН, «ё» заменена на «е».

1. **Заголовок новый:** «Беременность и роды без паники, глянца и советов «родишь — поймешь»» — по образцу «Первого года» («…советов из 1998 года»). На старой странице было «От планирования беременности до первой недели с новорожденным дома», эта формулировка теперь в первой строке текста под заголовком.
2. **Бонус Балансити.** На старой странице дата акции считалась скриптом как «сегодня + 2 дня». Здесь бонус без даты; если у акции есть настоящий срок, его нужно вписать в два места.
3. **Темы курса.** На старой странице не было списка уроков, только перечень тем. Если есть названия 14 уроков, их лучше показать списком.
4. **Экспертов на старой странице не было.** В описании для поисковиков старой страницы сказано «от редакции и доказательных врачей»; если есть имена врачей, их стоит добавить блоком, как на «Первом годе».
5. **Оплата и доступ** в вопросах — со страницы оформления `/course/school/enroll` на 16.10.2026.
6. **Отзывы** набраны текстом со скриншотов старой страницы (`/school/reviews/otziv-1,2,3,5,6,7.jpg`).
